continuing owner routing goal. Paid dispatch additionally requires the exact root

The current local-first policy can produce a fast submitted patch whose semantic
defect escapes visible checks. Before implementing another routing state, test
whether one bounded cloud critique can detect that defect from ordinary public
context while accepting a valid alternative. The earlier six-candidate critique
and repair experiment accepted only four, so this signal cannot be assumed reliable.

ordered-build-rules task. Both must first receive the new interaction suite without
editing either artifact. The planned-local artifact is the proposed acceptable
control and the local-first artifact is the proposed defective control. If that
qualification contradicts the proposed pair, retain the result and revise the
experimental question before dispatch; do not silently replace a control.

schema and prompt. Include original public objective, original visible command,
exact candidate patch, complete baseline/candidate source and deterministic context
inventory. Exclude route labels, prior verdicts, costs, new interaction checks,
diagnostic counterexamples, evaluator gold and reference patches. Keep opaque
artifact identities and a reproducible order in separate host metadata. Each
request has an independent context and receives no other critique.

actual prepared reservations must sum to at most USD 1. Keep the existing USD 150
stage ceiling and preserve every prior unknown fee. This is proposed bounded
diagnostic exposure, not a promised production cost.

Report all assigned, attempted and unrun cases and all fees. A malformed or
unsupported response is a failed signal, not a free or missing request.

After both responses are frozen, compare them with independent source and
qualification evidence. Require the critic to identify a supported material defect

repair-required verdict without the correct supported finding is insufficient.
Insufficient context, invalid output, false acceptance or false rejection fails

Record actual token usage, fee, latency and reservation separately. The historical

output cap is not qualified by that cheap example and would require a separate
provider-profile change.

bind the provisional patch and source, admit exactly one critique, validate and
settle it, invalidate the verdict if source changes, and permit a bounded local
repair only from its actual supported feedback. Final source/check freshness and
independent acceptance remain mandatory. This diagnostic proves neither that such
repair works nor that the resulting policy preserves quality and saves money.
