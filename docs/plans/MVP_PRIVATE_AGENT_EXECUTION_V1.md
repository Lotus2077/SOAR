Date: 2026-09-11.

Status: **Approved for implementation, synthetic local qualification and local
artifact sessions** by the owner's instruction to complete the next sequence.
The [design](MVP_PRIVACY_FIRST_AGENT_V1.md) remains the requirements baseline.
This file supplies execution bounds; it does not declare any gate passed.

## Scope and order

1. Implement a real host-owned outbound broker and a general goal/tool/verification
   loop. Generated programs run in credential-free, network-disabled containers.
   Keep the legacy public coding flow explicitly separate. Private source labels
   apply to complete invocation context and derived requests, even if every
   detector reports no finding. Prove this with real controlled receivers and
   attempted worker network/filesystem bypasses before model task execution.
2. Provision pinned OpenAI Privacy Filter assets locally and run the separately
   specified 120-case synthetic calibration. Development and confirmation labels
   are authored independently before inference. Compare the existing deterministic
   baseline, OPF, configured local Presidio and OPF plus rules; record any unavailable
   candidate as untested, not a passing substitute. Confirmation stays sealed until
   one operating configuration is frozen. Inference is offline, on synthetic text.
3. Complete four bounded local-model sessions through the real general runtime,
   with synthetic private inputs and actual research, audit, website and editable
   PowerPoint deliverables. Use independent critical evaluators and visual checks.
   Exercise a durable pause/resume. Preserve every failed attempt; a diagnostic or
   repaired development attempt is not a replacement for fresh confirmation.
4. Freeze eight fresh task assignments, paired local versus permitted-cloud routes,
   and one additional unfamiliar composition task. Preserve the design's per-policy
   quality gate and disclosure constraints. Do not reveal confirmation tasks to
   runtime developers before the source/configuration freeze. Freeze exact paid
   provider, inputs, request ceilings and total API authority before any paid call.
   Then complete actual app and owner-task acceptance before a product MVP claim.

## Initial bounds

- Use synthetic data and public dependency/documentation retrieval only. Do not
  send real private user material to the GPU until deployment trust is verified.
- Existing local-model endpoint access is usable for synthetic task execution;
  this is not certification of its handling of real private information.
- Local inference: initially at most 40 model calls per artifact session, 4,096
  output tokens per call, 192 KiB serialized input and 30 minutes per session.
  At most four first-pass Stage B sessions. Freeze source/input identities before
  each first pass; a failure triggers diagnosis rather than silent replacement.
- Generated tools: one container per restricted context, no network, no host
  mounts or Docker socket, no ambient secrets, dropped capabilities, no privilege
  escalation, process/memory/CPU/output/file-size limits and bounded cleanup.
  Provision dependencies separately before these runs, with no private inputs.
- Filter trial: one pinned checkpoint, one local process at a time, at most four
  CPU threads and one hour per frozen corpus pass. Check capacity before loading;
  record failures and peak resident memory. No cloud filter fallback.
- Boundary tests: controlled synthetic receivers only, explicit timeouts and
  cleanup. No unapproved real external action or public deployment.
- No transfer of the old USD 29.10 proposal. Paid Stage C remains undispatched
  until concrete cost authority is recorded. No cloud credential is needed for
  implementation, offline qualification or the four local sessions.

## Evidence and stopping rules

Keep corpus gold, task inputs, raw synthetic traces, model assets and generated
artifacts under ignored local working directories. Publish only source/configuration
identities, aggregate results and sanitized findings in tracked documentation.
Do not persist credentials or private endpoints. Model-generated completion is
provisional until the host checks required artifact identities and the independent
evaluator establishes critical quality. Tests of broker mechanics, detector accuracy,
task quality, app interaction and economics remain distinct evidence.

Any unauthorized transmission stops that boundary's admission. Invalid/incomplete
scans cannot authorize release. Quality failures remain failures even with zero API
cost. A blocked or unsupported task is unfinished. Use source changes and separately
identified development runs to learn, then fresh confirmation after a new freeze.
