### BL-20261118-0652-desktop-research-task-view -- 2026-11-18 -- 13a.1, part 3: the task view offers local research per task and shows what the stage did from its own counts, with research stops worded and the pause and quit offers truthful mid-stage

Status: `Implemented`

Scope or hypothesis: Part 3 of 13a.1 (decision 8 of BL-20261118-0438-desktop-local-research-13a-design). It adds the per-task option, the badge, the sentences, and the pause and quit warnings, on part 2's snapshot (BL-20261118-0619-desktop-research-stage-wiring), and it is stacked on part 2 (#164). The pull request's description holds the detail.

Decisions:
1. **The form.** A "Local research first (beta)" checkbox appears only when the host reports the beta, and is disabled, with the reason, when the card is refused. When checked, it fixes the heavy profile and local-only routing, and clears and disables the typed URLs. Like create, it then needs an input file and a document deliverable. It is on only while the host offers it: a later check that withdraws it unticks it.
2. **The badge and the section.** The task shows "Local research (beta) · serving card of <date> · <stage>": not started, reading the sources, packet ready or stopped before the writer, with "packet ready, with a disclosed gap" kept unwired for the protocol revision now before the owner. A "Research stage" section lists each stage's own counts and no fixed sentence: calls and replies cut at the output limit; the host's plan or the synthesis skeleton when used; passages read and repairs; the packet's trim; held passages kept at a first reading, once the stage records that count (proposed by lane S-pipe); and the stage's requests, counted apart from the model attempts. A row the stage stopped in shows its settled calls, never a passage count (an unfinished extraction records 0 passages), and no count a row does not hold is shown as zero.
3. **The stops.** These research stops each get their own sentence: extraction incomplete, mandatory budget, clock, unreadable source and no evidence. A stage request denial, which is every stage stop but a cancel, is worded from its last row's `denied` code: a request that was sent and failed, the request allowance or fee cap, the clock, the size, the token checks, the scanner, or the code by name. Any other research code is named, with "this task cannot resume". The writer's sentences stay main's. A spent writer allowance ends `bounded_allowance_exhausted` (runner.ts), which now has its own sentence. The judge's unjudged claims stay in Claim judgements.
4. **Pause and quit.** While a stage runs, from the moment the running task records its research input, the task warns that a pause ends it. The quit offer says the task will end and cannot resume, instead of promising a resume. The controller tells the quit offer whether a stage is in progress.
