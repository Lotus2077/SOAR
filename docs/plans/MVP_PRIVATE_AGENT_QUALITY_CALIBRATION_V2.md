## Hypothesis and implementation

The first task used a wrong constant as its own test oracle. The separate verifier
then found one discrepancy but downplayed it and omitted other material errors.
Expose current execution budgets and require a source-evidence bundle with fixed,
answer-free critical requirement IDs, artifact quotations, original-source excerpts,
executed numerical comparisons and direct pointers to submitted JSON values.

The immutable host check resolves actual values itself, rejects every declared
mismatch regardless of a model verdict, requires coverage of declared requirements,
and replays the calculator without its previous results. Replay has no network,
subprocess/thread capability or write permission under this contract; changed files,
stale results, nonfinite numbers and malformed evidence fail. A bounded calculator
may read its input and submitted artifacts and emit JSON on stdout. The generated
helper exposes the same check to the agent without any evaluator answers.

This is necessary consistency evidence. A calculator can still implement a wrong
formula, hardcode an answer or quote irrelevant text. Requirement completeness,
source interpretation, conditional reasoning and final correctness remain separate
independent acceptance gates. No model-authored pass flag grants acceptance.
