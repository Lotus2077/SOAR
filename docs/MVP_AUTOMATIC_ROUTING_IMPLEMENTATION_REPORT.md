# Automatic routing implementation and runtime verification

Date: 2026-09-11. **Implemented and verified for routing mechanics.** The app now
offers an explicit experimental Automatic choice. It selects an existing concrete
route before generation and records why. The default and explicit policy choices
retain their meaning. No new real-model quality or savings result is claimed.

The selector uses the admitted committed source, not working-tree changes or
renderer-supplied counts. A baseline beyond the critic's existing 64-file or
98,304-byte limit goes directly to prepared cloud. An eligible baseline uses local
drafting, one cloud critique and optional local repair when its profile and fee
headroom are available; otherwise it selects cloud before any local request.
Invalid source or original task text, cancellation and admission drift stop work.

The selection receipt binds the committed tree, revision, source counts, route,
reason, nonsecret configuration and reduced episode ceiling. The controller
rechecks it before starting and against materialized source before worker launch.
Changing source, model, endpoint, prices, execution entry points or relevant limits
cannot silently alter a created task. Session key rotation is permitted. Workers
receive the existing concrete policy; no database migration or new worker protocol
was introduced.

calls, thirteen total requests and at most USD 0.70. Automatic cloud work uses at
